Aquí van los materiales descargables que ofrecen las páginas de servicio
(el reporte de ejemplo de vibraciones, entre otros).

Para activar la descarga en una página, agrega el bloque "recurso" al JSON
del servicio en data/servicios/<slug>.json, por ejemplo:

  "recurso": {
    "titulo": "Reporte de ejemplo de análisis de vibraciones",
    "descripcion": "Un reporte real, anonimizado, para que veas exactamente qué entregamos.",
    "incluye": [
      "El espectro con el hallazgo marcado",
      "Severidad y diagnóstico por equipo",
      "La recomendación concreta de intervención"
    ],
    "archivo": "/documentos/reporte-ejemplo-vibraciones.pdf"
  }

El archivo debe existir en esta carpeta con ese mismo nombre.
